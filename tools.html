Virtual fluids laboratories for CE 323

Four browser-based simulations of the Boise State CE 323 fluids experiments, built while I taught the lab. Each one walks through setup and calibration, lets you run the experiment and record readings, and then checks your own calculations against the simulated apparatus. They run entirely in the browser with no accounts or installs.
